# Open code
[Link para a página do projeto](https://opencode.ai/)

Após alguns meses usando o Claude code, notei que usa-lo era um pouco engessado, de modo que o claude code tornava tudo estrito e dedicado para os modelos da Anthropic, como o formato do claude.md, a forma como as rules eram definidas, skills etc, fora que eu ficava limitado a usar apenas os modelos da Anthropic.

O Open code surge justamente para sanar esse problema. O Open code é uma solução open source de Harness para AI. Ele é a aplicação de terminal que nos permite conectar o agente à qualquer modelo de nossa preferência e criar arquivos de configuração/harness muito mais flexíveis e reutilizaveis por outros providers.

## Instalação 
> curl -fsSL https://opencode.ai/v2/install | bash
